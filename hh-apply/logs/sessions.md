# Лог сессий hh-apply

Накопительный лог. Каждая сессия дописывает сюда новый блок —
существующие записи не перезаписываются и не удаляются.

Формат блока:

```
## Сессия ГГГГ-ММ-ДД

| Вакансия | Компания | Статус | Комментарий |
|---|---|---|---|
| ... | ... | Отправлено / Пропущено | ... |

Итого: найдено N, отправлено N, пропущено N.
```
