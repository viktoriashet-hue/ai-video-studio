# hh-apply

Инструмент для полуавтоматических откликов на hh.ru через Claude Code.

Соискательский API hh.ru закрыт с 15 декабря 2025 года, поэтому здесь
нет бэкенда и нет OAuth — вся работа идёт через встроенную
браузерную интеграцию Claude Code (Claude in Chrome): Claude видит и
кликает страницу в твоём обычном залогиненном Chrome, как это делал
бы человек.

## Требования

- Платный план Claude (Pro / Max / Team / Enterprise).
- Установленное расширение **Claude in Chrome** (Chrome Web Store,
  версия 1.0.36+).
- Вход в аккаунт Claude через `/login` — с API-ключом браузерная
  интеграция не работает.

## Как запустить

1. Заполни `profile.md` реальным опытом — только эти факты попадут в
   письма, ничего от себя скиллы не добавляют.
2. Из этой папки:

```
claude --chrome
/hh-apply Маркетолог Москва 10
```

Аргументы: должность, город, лимит откликов за сессию (по умолчанию
10, если не указать).

Если работодатель прислал в сообщениях hh.ru приглашение на
собеседование со ссылкой на внешнюю анкету (Google Forms и т.п.):

```
/hh-fill-form
```

## Как это работает

- `/hh-apply` открывает hh.ru в браузере, ищет вакансии по фильтрам,
  отбирает и упорядочивает их по свежести публикации (скилл
  `hh-vacancy-filter`) — сначала все вакансии за последние 24 часа,
  и только когда они закончились, вакансии от 24 часов до 3 суток;
  всё, что старше 3 суток, вообще не рассматривается.
- Для каждой подходящей по свежести вакансии готовит сопроводительное
  письмо (скилл `hh-cover-letter`), опираясь только на `profile.md`.
- Перед КАЖДЫМ откликом Claude показывает вакансию, найденные
  пересечения с опытом и текст письма — и ждёт твоего решения:
  «отправляй» / «пропусти» / «перепиши иначе». Без явного
  подтверждения отклик не отправляется.
- Вакансии с малым совпадением пропускаются автоматически, без
  генерации письма и без траты лимита откликов.
- По итогам сессии в `logs/sessions.md` появляется новая запись —
  старые записи не затираются.
- `/hh-fill-form` (скилл `hh-interview-form`) — отдельная задача:
  находит в сообщениях hh.ru приглашение со ссылкой на внешнюю форму
  (Google Forms и т.п.), заполняет её ответами на основе `profile.md`
  и показывает ПОЛНЫЙ черновик всех вопросов и ответов перед
  отправкой — форму, в отличие от отклика, потом не отредактировать,
  поэтому здесь подтверждение обязательно на весь набор ответов
  целиком. Если данных для ответа не хватает — Claude спросит, а не
  придумает.

## Если что-то пошло не так

При капче или требовании залогиниться Claude остановится и попросит
тебя пройти это вручную в браузере — это нормальное поведение, а не
баг. Так же он остановится, если вёрстка hh.ru выглядит непривычно —
вместо того чтобы гадать кликами.

## Важно

Не проси Claude «откликайся на всё подряд без вопросов». Вся ценность
инструмента — в контролируемости и в том, что каждое письмо реально
соответствует вакансии, а не в скорости массовой рассылки.
