# hh-cover-letter

## Вход
- Текст вакансии (обязанности, требования, условия).
- profile.md — профиль опыта пользователя.

## Что делать

1. Выдели 3-5 ключевых требований вакансии.
2. Для каждого найди конкретное соответствие в profile.md — только
   то, что там реально написано, ничего не досочиняй. Раздел
   "Портфолио: детальные кейсы" содержит цифры (CAC, CR, ROI, рост
   подписчиков, выручка) по нишам — приоритетно бери оттуда кейс,
   максимально близкий к нише/задачам вакансии (медицина, инфобизнес,
   личный бренд, performance и т.д.), и используй именно ту цифру,
   которая отвечает на конкретное требование работодателя.
3. Если пересечений мало или они натянуты — верни:
   `match_score: low` и краткую причину, письмо НЕ пиши.
4. Если пересечения есть — напиши письмо:
   - 800-1200 знаков
   - без канцелярита и без фразы "с удовольствием откликаюсь на
     вашу вакансию" — сразу по существу
   - только на основе реальных фактов из profile.md
   - веди с самой релевантной цифрой/кейсом под требования именно
     этой вакансии, не перечисляй все кейсы подряд

## Формат вывода

```json
{
  "match_score": "high | medium | low",
  "matched_requirements": ["...", "..."],
  "cover_letter": "текст письма или пусто, если low"
}
```
