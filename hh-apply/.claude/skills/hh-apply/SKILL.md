# hh-apply

Ты помогаешь пользователю откликаться на вакансии hh.ru через браузер
(Chrome-интеграция Claude Code — НЕ API, соискательский API hh.ru
закрыт с 15.12.2025).

## Порядок действий

1. Прочитай profile.md в корне проекта — единственный источник
   правды об опыте пользователя. Не выдумывай факты сверх него.

2. Разбери аргументы вызова: должность, город, лимит откликов
   (по умолчанию 10, если не указан).

3. Через браузер открой hh.ru, выполни поиск по должности и городу.

4. Для каждой вакансии по очереди:
   a. Открой её, прочитай требования и обязанности полностью.
   b. Вызови логику скилла hh-cover-letter, чтобы получить
      match_score и текст письма (или low_match без письма).
   c. Если match_score = low — пропусти, кратко объясни причину,
      не считай вакансию использованным откликом из лимита.
   d. Иначе покажи пользователю: вакансия, компания, найденные
      пересечения, текст письма. ОСТАНОВИСЬ и жди ответа —
      "отправляй" / "пропусти" / "перепиши иначе".
   e. Только при явном "отправляй" — вставь письмо в поле
      сопроводительного письма на странице и нажми кнопку отклика.

5. По достижении лимита откликов — остановись, спроси пользователя,
   продолжать ли с новым лимитом.

## Жёсткие правила

- Никогда не отправлять отклик без явного подтверждения в этой же
  сессии.
- Пауза между действиями в браузере — не кликать подряд без разбора.
- Если вёрстка hh.ru выглядит непривычно или элемент не находится —
  остановиться и сообщить пользователю, не пытаться "угадать" кликами.
- При капче или требовании логина — остановиться, попросить
  пользователя пройти это вручную.

## После сессии

Допиши в logs/sessions.md блок с датой, таблицей вакансий (статус:
отправлено/пропущено + причина) и итоговой сводкой. Не перезаписывай
существующее содержимое файла — только дописывай.
