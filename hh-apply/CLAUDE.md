# Проект hh-apply

Это инструмент для полуавтоматических откликов на hh.ru через браузер
(Chrome-интеграция Claude Code), НЕ через API — соискательский API
hh.ru закрыт с 15 декабря 2025 года.

Запускается как `claude --chrome` из этой папки, дальше — скилл
`hh-apply` (вызывается как `/hh-apply <должность> <город> [лимит]`).

## Жёсткие правила (не нарушать ни при каких обстоятельствах)
- Никогда не отправлять отклик без явного подтверждения пользователя
  на конкретную вакансию в этой же сессии.
- Не превышать лимит откликов за сессию, заданный пользователем в
  команде /hh-apply (по умолчанию 10).
- Делать паузу между действиями в браузере (не долбить сайт кликами
  подряд).
- Если страница hh.ru выглядит непривычно (изменилась вёрстка,
  не находится ожидаемый элемент) — остановиться и сообщить
  пользователю, не пытаться "угадать" через произвольные клики.
- При капче или требовании логина — остановиться и попросить
  пользователя выполнить это вручную в браузере.
- Уровень английского пользователя — A2 (см. profile.md, раздел
  "Языки"). Если в требованиях вакансии указан уровень английского
  выше A2 (B1/Intermediate, B2/Upper-Intermediate, C1/Advanced,
  "разговорный", "свободный", "fluent" и т.п.) — вакансию пропустить
  сразу, без генерации письма, и не считать её использованным
  откликом из лимита.
- Порядок отбора вакансий — по свежести публикации (см. скилл
  hh-vacancy-filter): сначала все вакансии за последние 24 часа, и
  только потом, когда они закончились, — вакансии от 24 часов до
  3 суток. Вакансии старше 3 суток не рассматривать вообще.
- Никакого фонового процесса/демона — только сессии по явному запросу
  пользователя.
- Никакой работы с hh.ru API — он закрыт для соискателей, весь доступ
  идёт только через реальный залогиненный браузер.

## Файлы проекта
- profile.md — источник правды об опыте пользователя. Использовать
  только то, что там написано, не додумывать факты.
- logs/sessions.md — сюда дописывать сводку по итогам каждой сессии
  (не перезаписывать историю).
