# Kinetic Steps («Синие шаги»)

Безлицевой рилс-инструкция 15–30 сек, где смысл несёт только движение текста и простых UI-мокапов. Изучено по референсу https://www.instagram.com/reels/Dc5QXC7gZ5b/ (25.5 сек, 1080×1920, ~16 сцен). Мы берём **стиль и грамматику движения**, не тексты и не брендинг автора: тексты всегда Викины, плашка автора — её аккаунт.

Полный разбор кадров и тайминги референса → `references/style-dna.md`. Рабочий шаблон → `templates/reel-9x16.html` (проверен: `lint` 0 ошибок, рендер 23 сек за ~1 мин).

## Когда запускать

- «сделай рилс в синем стиле / по шагам / как тот референс»
- рилс-инструкция «как сделать X с помощью ИИ за N шагов»
- нужен моушн-рилс без съёмки, из текста залетевшего поста

Не для: talking-head (→ `talking-head-recut` / video-use), субтитров поверх живого видео (→ `embedded-captions`).

## Пайплайн

1. **Сценарий по битам.** Разложи текст на 6–9 сцен по схеме ниже. Хук из источника переносится без изменений смысла (правило Вики). Одна мысль — одна сцена, 1–3 слова на экране одновременно, максимум 2 строки.
2. **Покажи Вике раскадровку текстом** (таблица: время · фон · слова · мокап · переход) — одним сообщением. Она даёт короткие команды; если ответа нет — бери свой вариант и рендерь draft.
3. **Сборка.** Создай `videos/<slug>/`, скопируй туда `templates/reel-9x16.html` → `index.html` и `assets/gsap.min.js` (сеть к CDN закрыта — GSAP только локально). Меняй тексты, тайминги, мокапы; структуру переходов и токены не трогай без причины.
4. **Проверка.** `npx hyperframes lint` (ожидаемы только предупреждения `nested_structure_needs_subcomposition` и `timeline_track_too_dense` — это нормально для монолитного шаблона), затем draft-рендер и контакт-лист кадров через ffmpeg `tile` — посмотри глазами: текст не вылезает за 90px поля, подчёркивания по ширине слова, переходы не открывают пустой кадр.
5. **Рендер.** `npx hyperframes render --quality draft -o renders/draft.mp4` → показать → финал без `--quality`. В облаке без chrome-headless-shell: `export HYPERFRAMES_BROWSER_PATH=/opt/pw-browsers/chromium_headless_shell-*/chrome-linux/headless_shell`.
6. Все файлы — в папку проекта (`edit/` или `videos/<slug>/renders/`), репо чистый.

## Режим «Карусель → рилс со скринами» (утверждён Викой 16.10.2026)

Когда Вика даёт ссылку на свою карусель со скриншотами (инструкция по шагам):

1. **Слайды в полном качестве.** Открой пост во встроенном браузере, листай кнопкой «Далее» и собирай `main ul li img` с naturalWidth > 500. CDN Instagram из песочницы закрыт: рисуй каждую картинку в canvas в браузере → `toDataURL('image/jpeg',0.9)` → верни строку из javascript_tool по одной картинке (больше ~200 тыс. символов режь на части). Слишком большой ответ сохраняется файлом в tool-results — декодируй его python'ом, не читая в контекст.
2. **Кропы.** Посмотри каждый слайд, вырежи PIL'ом только UI-скрин (без текста карусели) и верх обложки с фото Вики (`hero`).
3. **Генератор.** Скопируй `scripts/carousel_to_reel.py`, заполни `SHOTS` (размеры кропов) и `STEPS`: фон, ШАГ N, глагол + объект + короткая подпись. Аннотации задаются в пикселях исходного кропа: `circle` / `circle2` = (x, y, w, h) — обводка от руки; `arrow` = (старт, цель) — изогнутая стрелка с наконечником; `check` — зелёная галочка; `zoom` — зона, к которой едет камера; `chips` — примеры промптов. Стрелку начинай сбоку или над карточкой, не поверх заголовка.
4. **Тексты:** хук обложки без изменений; шаги — 1–2 слова крупно + подпись из слайда; финальная мысль — из слайда «я так веду аккаунты»; CTA по правилам ниже.
5. Проверка: `snapshot` на t0+2.0 и t0+3.3 каждого шага. Камера: 1.38 для узких скринов, 1.18 для широких (иначе карточка уходит за край). Затем рендер.

Скорость: 6 шагов ≈ 33 сек, рендер ≈ 1.5 мин.

## Структура ролика (по референсу)

| # | Бит | Фон | Что на экране | Длина |
|---|-----|-----|---------------|-------|
| 1 | Хук-стопка | графит + сетка | 3 слова сменяют друг друга: «Claude» → «ТЕПЕРЬ» (синее) → *сам* (курсив, подчёркивание) | 1.5–2 c |
| 2 | Обещание | крем | мелкое чёрное слово сверху + ОГРОМНОЕ синее слово, ниже мокап | 2–2.5 c |
| 3–6 | Шаги | чередовать синий / графит / крем | глагол-команда («СКАЧАЙ», «УСТАНОВИ», «ЗАГРУЗИ», «ОПИШИ») + объект + UI-мокап (карточки, окно, чипы, панель) | 2.5–3.5 c каждый |
| 7 | Результат | графит | «ЧЕРЕЗ» + счётчик в кольце 0→N + «МИНУТ» + курсивное *готово* | ~3 c |
| 8 | Вопрос | графит | «ХОЧЕШЬ / ТАК ЖЕ?» | ~1.3 c |
| 9 | CTA | крем (iris-переход) | ПИШИ СЛОВО / **КАНАЛ** / В КОММЕНТАРИЯХ / серая строка → чёрная + подчёркивание | 3–4 c |

Средний бит текста — **0.35–0.5 c**, сцена — 1.5–3.5 c. Экран не стоит ни секунды: если нечего показывать, медленно вращается искра или «плывёт» мокап.

Шрифты (встроены в HyperFrames, кириллица есть): **Inter 900** капсом, трекинг −0.035em, интерлиньяж 0.95 — все слова; **Playfair Display italic 400** строчными — 1 слово-эмоция на ролик максимум 2 раза (*сам*, *готово*). Размеры: главное слово 150–190px, подводка 46–92px, служебное 20–22px с трекингом 0.32em.

Постоянный интерфейс поверх всех сцен: кикер слева сверху («CLAUDE × КАРУСЕЛИ»), плашка автора справа сверху (тёмная пилюля, синий кружок-аватар, «автор / @аккаунт»), подпись внизу слева («CLAUDE CODE / SKILLS»). Нижние 300px и правые 140px — зона интерфейса Instagram, туда не ставим смысл.

## Словарь движения

- **Стопка слов (word stack):** новое слово въезжает снизу `y:60→0, scale:.9→1, 0.32s power3.out`; предыдущее уменьшается вверх `scale→0.42, y:-120` и становится подписью над ним. Через 2 бита оба уходят вверх с fade.
- **Акцент-подчёркивание:** линия 8px, `scaleX 0→1`, origin left, 0.35–0.45s, стартует через 0.15s после слова. Ширина = ширина слова (обёртка `.hl`).
- **Карточки/мокапы:** въезд снизу `y:200→0` с поворотом ±6° → 0, `back.out(1.5)`, стаггер 0.15–0.45s. «+» между карточками — scale-pop.
- **Чипы 2×2:** `scale .6→1, back.out(1.8), stagger .14`; в конце один чип «включается» синим — показывает выбор.
- **Счётчик:** кольцо рисуется `strokeDashoffset`, цифра считает 0→N, обе 1.1s `power2.inOut` синхронно.
- **Серое → чёрное:** финальная строка CTA сначала серая, через ~0.8s темнеет и подчёркивается синим — второй крючок досмотра.
- **Искра (4-лучевая звезда, контур):** pop `scale 0→1, rotation −90→0`, потом медленное вращение `rotation +90` linear.

## Переходы (только эти три)

1. **Ступенчатая шторка** (основной, 4 из 6 стыков): 5 колонок по 216px цвета следующей сцены растут снизу `scaleY 0→1`, 0.26s `power3.inOut`, стаггер 0.02 → «лесенка». Клип перехода стоит на треке 5 и заканчивается ровно в момент старта следующей сцены.
2. **Угловой блок:** квадрат цвета следующей сцены из правого верхнего угла `scale .08→1`, 0.28s `power3.in` — для входа на синюю сцену.
3. **Iris (круг из центра):** перед CTA, круг кремового цвета `scale 0→1`, 0.38s `power3.in`.

Не использовать: crossfade, blur, zoom-through, push-slide — они из другого стиля (MOTION_PHILOSOPHY в CLAUDE.md относится к mama_mozg, здесь не действует).

## Правила текста (Вика)

- Хук и смысл слайдов 1–2 источника — без изменений смысла; остальное можно сократить до 1–3 слов на бит.
- CTA рилса: кодовое слово **КАНАЛ**, смысл — «Пиши слово КАНАЛ и получи доступ к инструкции по созданию ИИ-агента». ОПОРА в рилсах не используется.
- Никогда: слово «мотив», квадратные скобки, ник @vikashet, тексты, которые звучат как написанные ИИ.
- Обращение на «ты» (пиши, установи, опиши), если источник не на «вы».
- Плашка автора: маркетинг/ИИ → `@corka_freuda` (или `@shetnavika`), психология → `@balance_8life`. Уточнить один раз, если неочевидно.
- Описание к рилсу, хештеги и SEO — отдельным скиллом `rils-oformlenie` (в чате), здесь только видео.
