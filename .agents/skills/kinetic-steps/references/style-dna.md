# Style DNA — разбор референса

Источник: https://www.instagram.com/reels/Dc5QXC7gZ5b/ (автор zhenya_pro_dvizhenie, тема «монтаж через ChatGPT + Codex + Remotion/HyperFrames», CTA на слово). 25.5 сек, 1080×1920. Кадры сняты покадрово через canvas, цвета — пипеткой по пикселям.

Тексты автора здесь пересказаны только для понимания ритма — в ролики Вики не переносим.

Итого ~16 визуальных состояний за 25 сек → новое состояние каждые ~1.6 сек, новое слово каждые 0.4–0.5 сек.

## Цвета (пипетка)

- графит `#17181F`
- крем `#F5EFE7`
- электрик-синий `#186AFF` / `#1768FE` → токен `#1A6AFF`
- голубой на тёмном (кольцо, цифра) `#56B6FD`
- серый неактивный текст ≈ `#8B8C96`

## Почему это работает (выводы для агента)

1. **Один акцент на кадр.** В каждом кадре ровно одно крупное слово — синее (на креме) или голубое (на графите). Остальное — мелкая чёрная/белая подводка.
2. **Ритм = удержание.** Смена каждые 0.4–0.5 c не даёт свайпнуть; мокапы дают глазу «доказательство», что инструкция реальная.
3. **Фон как глава.** Смена фона = новый шаг. Зритель интуитивно считает шаги по цветам.
4. **Курсив — эмоция.** Единственное «человеческое» слово (*сам*, *готово*) набрано курсивной антиквой — контраст с жёстким гротеском.
5. **Цифры продают.** «2 плагина», «10 минут» — крупная цифра всегда отдельным объектом и с анимацией.
6. **CTA в два такта.** Сначала кодовое слово, потом серая строка «пришлю инструкцию» оживает — второй стимул к комментарию.
7. **Постоянная плашка автора** сверху справа во всех кадрах — брендинг без отдельного логотипа.

## Чего в референсе нет (и не добавляем)

Говорящей головы, фото, градиентов, свечений, 3D, размытия, наклонных шрифтов кроме курсива-акцента, больше трёх цветов.
