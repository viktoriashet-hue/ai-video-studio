# A-roll + Motion Splice — живое видео и моушен на одном звуке

Разобрано по двум референсам (рилс Молянова про Claude Opus 4, 94 с, и его ремейк, 58 с) —
полный покадровый и звуковой разбор: `references/reference-breakdown.md`.

## Главный принцип (из референсов)

**Звук никогда не режется вместе с картинкой.** Голос спикера записан одним дублем
(после чистки паразитов video-use) — это мастер-дорожка. Моушен-сцены *не имеют своего звука*:
они просто закрывают кадр, пока спикер продолжает говорить. Зритель «видит» то, что слышит.

```
голос:   ████████████████████████████████████████████████████  ← непрерывно
картинка: [ ЛИЦО ][ моушен 1 | моушен 2 ][ ЛИЦО zoom ][ моушен 3 ][ ЛИЦО ]
субтитры: ─ слово ─ слово ─ слово ─ слово ─ слово ─ слово ─ слово ─  ← сквозные, одно место
звук FX:        whoosh   swipe pop pop       whoosh  tick tick  swipe
```

Что «склеивает» два мира в один ролик:
1. **Один голос** без единого разрыва (`-map 0:a`, побитово тот же — проверено).
2. **Сквозные субтитры** — одинаковый шрифт и позиция на лице и на моушене, последним слоем.
3. **Стык по слову**: картинка меняется на начале слова-якоря или в паузе между словами.
4. **Моушен иллюстрирует произносимое слово**: «письмо» → появляется конверт, «84%» → счётчик.
5. **Звуковые эффекты на стыках** (whoosh/swipe) — «шов» слышен, а не только виден → `sound-design`.
6. **Punch-in** на возврате к лицу: план чередуется 100% / 112%, поэтому повтор лица не выглядит прыжком.

## Ритм (замеры по референсам)

| Параметр | Молянов (оригинал) | Ремейк | Наша норма |
|---|---|---|---|
| Доля моушена в хронометраже | ~65% | ~70% | 55–70% |
| Первый моушен | 5.5–7 с | 3.3 с | после хука, 3–6 с |
| Блок лица | 4–8 с | 2–6 с | 2–7 с (хук, эмоция, мнение, «самое забавное») |
| Блок моушена | 7–17 с | 5–15 с | 4–15 с, внутри смена сцены каждые 1.5–3 с |
| Новый элемент в моушене | каждые ~0.6–1 с | ~0.8 с | на каждое ключевое слово |

**Когда показывать лицо:** хук и первые 1–2 фразы; эмоциональные реплики («И знаете, что делает?»,
«Самое забавное…»); личное мнение; призыв в конце. **Когда моушен:** факты, цифры, процесс,
«что было дальше», цитаты из документов, сравнения.

## Пайплайн

1. **Исходник уже смонтирован** (шаг 1 video-use: паразиты вырезаны, есть транскрипт с таймингами слов
   `edit/transcripts/*.json`). Транскрипцию не запускать без команды Вики (правило CLAUDE.md).
2. **Раскадровка** — таблица одним сообщением Вике: `время · слова · ЛИЦО/МОУШЕН · что на экране · переход`.
   Если ответа нет — бери свой вариант и делай draft.
3. **Моушен-клипы** — каждый блок моушена = отдельная HyperFrames-композиция 9:16 без звука,
   длительностью ровно как отрезок речи (берём из транскрипта). Тайминги появлений привязывай к словам
   *относительно начала блока*. Стиль — бренд mama_mozg / MOTION_PHILOSOPHY из CLAUDE.md
   (или стиль, который Вика назвала). Рядом с клипом пиши `<clip>.events.json` — список событий для звука:
   ```json
   [{"t": 0.9, "type": "appear"}, {"t": 2.1, "type": "typing", "dur": 1.4},
    {"t": 4.0, "type": "counter", "dur": 1.2, "steps": 10}, {"t": 5.6, "type": "reveal"}]
   ```
   Типы: appear / icon / pop · click / select / cursor · typing (dur) · key · counter (dur, steps) ·
   reveal / fact / slam · alert / message / cta · error / negative / warning · success / check · sparkle · glitch · drop.
4. **План склейки** `edit/splice.plan.json` (пример: `examples/splice.plan.json`):
   ```json
   {
     "aroll": "final_cut.mp4", "words": "transcripts/final_cut.json",
     "fps": 30, "size": [1080, 1920], "out": "spliced.mp4",
     "auto_punch": true, "punch_scale": 1.12, "punch_focus_y": 0.38,
     "captions": "captions.ass",
     "segments": [
       {"start": 3.33, "end": 20.9, "src": "../motion/block1.mp4", "enter": "slide_up", "exit": "cut",
        "events": "../motion/block1.events.json"}
     ]
   }
   ```
   Пути — относительно файла плана. `start/end` — секунды в A-roll; скрипт сам притягивает их к границам слов
   (±0.25 с) и к кадру. Соседние блоки встык = смена сцены «моушен → моушен».
5. **Склейка:**
   ```bash
   python3 .claude/skills/aroll-motion-splice/scripts/splice.py edit/splice.plan.json --draft   # черновик
   python3 .claude/skills/aroll-motion-splice/scripts/splice.py edit/splice.plan.json           # финал
   ```
   На выходе `spliced.mp4` + `spliced.seams.json` (все стыки и события моушена в абсолютном времени).
6. **Самопроверка до показа Вике:**
   - контакт-лист стыков: `ffmpeg -i edit/spliced.mp4 -vf "select='between(t,T-0.15,T+0.15)+…',scale=135:240,tile=12x4" -vsync 0 -frames:v 1 edit/seams.jpg` — посмотри глазами: нет пустых/чёрных кадров, переход читается;
   - звук побитово равен A-roll (`ffmpeg -i X -map 0:a -f s16le - | md5sum` у обоих);
   - субтитры одинаковы на лице и моушене, не перекрыты.
7. **Звук** → скилл `sound-design` (берёт `spliced.seams.json`).

## Переходы (`enter` / `exit`)

| Переход | Что делает | Когда (по референсам) |
|---|---|---|
| `cut` | жёсткая склейка по слову | 70% всех стыков — основа |
| `slide_up` | моушен въезжает снизу, easeOutCubic 0.28 с | первый вход в моушен (Молянов, 7 с) |
| `slide` / `push` | въезд справа | смена темы |
| `flash` | белая вспышка 0.25 с | «удар» — новый важный факт |
| `blur` | размытие ±0.12 с | мягкий возврат, ремейк при входе в моушен |
| `glitch` | RGB-сдвиг + шум + дрожь 0.2 с | «сбой», тема ИИ/угроза (Молянов, 41 с) |
| `zoom` | зум-проброс с размытием | опенер / резкий акцент |

Не больше одного «громкого» перехода (flash/glitch/zoom) на 8–10 секунд, иначе дёшево.

## Ошибки, которых избегать

- Резать звук на стыке или класть звук моушен-клипа поверх голоса — **никогда**. Моушен рендерится без аудио.
- Менять картинку посреди слова — режь в паузу или на начало слова (скрипт притягивает сам).
- Моушен, который не совпадает со словом по смыслу/времени — ломает ощущение «одного ролика».
- Разные субтитры на лице и на моушене (шрифт/позиция) — главный признак «склеено из кусков».
- Два блока лица подряд в одном масштабе — включён `auto_punch`, не выключай без причины.
- Моушен короче отрезка — скрипт держит последний кадр, но лучше рендерить точно по длине.
