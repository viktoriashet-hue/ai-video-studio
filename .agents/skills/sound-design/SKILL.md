# Sound Design — эффекты и подложка на одном голосе

Правила сняты с референсов (разбор спектрограмм и mid/side — `references/reference-breakdown.md`):
эффекты и музыка живут **по бокам стереобазы**, голос — **в центре и всегда сверху**.

## Что звучит и где (таблица по умолчанию)

| Момент | Звук | Уровень | Выравнивание |
|---|---|---|---|
| лицо → моушен | `whoosh-short` | −9 dB | пик звука = кадр склейки |
| первый моушен в ролике | `riser` 1.6 с | −15 dB | «приземляется» в склейку |
| моушен → моушен (смена сцены) | `swipe` | −13 dB | пик = склейка |
| моушен → лицо | `swipe` тихо или тишина | −16 dB | пик = склейка |
| glitch-переход | `glitch-1` / `glitch-3` | −11…−13 dB | на кадре |
| flash-переход | whoosh + `impact-bass-1` | −9 / −17 dB | на кадре |
| появление иконки/элемента | `pop` | −17 dB | старт = кадр появления |
| курсор, клик, выбор | `click-soft` / `click` | −15 dB | на кадре |
| печать текста | `typing` на длину печати | −19 dB | старт печати |
| счётчик 0 → 84% | `tick` × N, сгущаются к концу | −15 dB, последний +3 | на каждом шаге |
| ключевой факт / цифра | `impact-bass-1/2` | −16 dB | на появлении |
| сообщение / CTA | `notification` | −13…−15 dB | на появлении |
| «неправильно», угроза | `error` | −15 dB | на появлении |
| тишина перед панчем | `sub-drop` + выключить подложку (`bgm.cuts`) | −14 dB | конец паузы |

Плотность: крупные звуки не чаще 1 на 0.35 с, мелкие UI — не чаще 1 на 0.12 с (`auto_cues.py` чистит сам).
На 60 секунд обычно 15–35 эффектов. Если всё звенит — убирай pop/click, оставляй стыки.

**Подложка:** по умолчанию `motion_only` — музыка только под моушен-блоками, с fade 0.35 с, на лице её нет
(так сделано в ремейке: лицо = «живой разговор», моушен = «кино»). Режим `full` — музыка всё время,
с дакингом −8…−10 dB под словами. Уровень подложки −24 dB до дакинга, голос всегда на 15+ dB громче.

## Пайплайн

```bash
SD=.claude/skills/sound-design/scripts

# 0. один раз в свежем окружении — дозаписать синтезированные звуки (swipe, tick, sub-drop, blip, reverse-whoosh)
python3 $SD/gen_sfx.py

# 1. авторасстановка по стыкам и событиям (из aroll-motion-splice)
python3 $SD/auto_cues.py edit/spliced.seams.json -o edit/cues.json --bgm motion_only --bgm-file ../assets/bgm/track.mp3

# 2. (по желанию) поправь edit/cues.json руками: добавить/убрать звук, сдвинуть t, gain_db

# 3. микс: голос + эффекты + подложка с дакингом → −14 LUFS
python3 $SD/sfx_mix.py edit/cues.json -o edit/final.mp4
```

Без склейки (например, готовый моушен-рилс или talking-head) — пиши `cues.json` вручную по таблице выше,
тайминги бери из транскрипта и таймлайна композиции. Формат и все поля — в докстринге `sfx_mix.py`.

**Музыка (bgm):** файла в репо нет. Варианты: трек от Вики (положи в `assets/bgm/`), `media-use`
(`resolve --type bgm`, нужен heygen CLI), Pixabay Music/YouTube Audio Library вручную. Нет трека —
`"file": null`, микс пройдёт без подложки.

## Проверка перед показом

1. `ffmpeg -i edit/final.mp4 -af ebur128=peak=true -f null - 2>&1 | tail -12` → I ≈ −14 LUFS, Peak ≤ −1 dBFS.
2. Спектрограмма side-канала (эффекты видны отдельно от голоса):
   `ffmpeg -i edit/final.mp4 -filter_complex "[0:a]pan=mono|c0=0.5*c0-0.5*c1,showspectrumpic=s=1600x300:scale=log" -frames:v 1 edit/sfx_check.png`
   — вертикальные «вжухи» должны стоять ровно на стыках из `spliced.seams.json`.
3. Голос разборчив под подложкой: в местах с музыкой mid-канал не «замылен».
4. Перечисли Вике коротко: сколько эффектов, где подложка, громкость.

## Библиотека звуков (порядок поиска)

1. `assets/sfx-user/` — свои звуки Вики (имя файла = имя эффекта, перекрывают встроенные).
2. `assets/sfx-extra/` — синтезированные `gen_sfx.py`: swipe, tick, sub-drop, blip, reverse-whoosh.
3. `agent/skills/media-use/audio/assets/sfx/` — 19 встроенных: whoosh, whoosh-short, whoosh-cinematic,
   pop, click, click-soft, key-press, typing, ping, chime, notification, sparkle, error, riser,
   glitch-1/2/3, impact-bass-1/2.

Все файлы автоматически нормализуются к одной опорной громкости, так что `gain_db` значит одно и то же
для любого звука. Расширить библиотеку: Pixabay Sound Effects (бесплатно, без атрибуции), Freesound (CC0),
Mixkit; платно — Epidemic Sound / Artlist. Скачанное — в `assets/sfx-user/`.

## Правила

- Голос — мастер. Его не режем, не компрессируем, не эквализируем в этом шаге.
- Моушен-клипы рендерятся **без звука**; все эффекты — только здесь, в одном миксе (иначе двойные вжухи).
- Эффект ставится на **кадр события**, не «примерно рядом». Для whoosh/impact — пиком на кадр.
- Эффекты шире голоса (`pan: wide`), голос в центре — так они не мешают разборчивости.
- Не больше 2 разных «громких» звуков на 10 секунд; повтор одного whoosh на однотипных стыках — это стиль, а не ошибка.
