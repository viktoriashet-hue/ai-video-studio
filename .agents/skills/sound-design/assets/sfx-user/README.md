# Свои звуки

Кидай сюда .wav / .mp3 — они важнее встроенных. Имя файла = имя эффекта в cues.json
(например `whoosh-short.mp3` здесь заменит встроенный whoosh-short во всех роликах,
а `mama-pop.wav` вызывается как `"sfx": "mama-pop"`).

Где брать без проблем с правами: Pixabay Sound Effects (бесплатно, без атрибуции),
Freesound (фильтр лицензии CC0), Mixkit SFX. Платно: Epidemic Sound, Artlist.
