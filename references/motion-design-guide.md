# Motion Design Guide — референс-библиотека стилей

Собрано из скриншотов/видео-референсов пользователя. Цель: при постановке задачи на
HyperFrames-видео — сверяться с этим файлом, выбирать подходящую стилевую семью,
не изобретать заново. Обновлять по мере поступления новых референсов.

Все пять семей стилей ниже — вариации одного и того же корневого принципа из
`CLAUDE.md` → MOTION_PHILOSOPHY: **чёрный/нейтральный фон + свет как единственный
источник бренда**. Разница между ними — в том, ГДЕ и КАК именно проявляется свет,
и насколько плотный/лёгкий визуальный язык.

| Задача | Стиль | HyperFrames route |
|---|---|---|
| Промо продукта/сервиса, портфолио услуг, дашборд-фичи | **A. Neon Dashboard/SaaS UI** | `/product-launch-video` |
| Карта/сеть/трекинг, гео-визуализация | **A (вариант с картой)** | `/product-launch-video`, `/general-video` |
| Мышление/мотивация/бизнес-совет, объясняем идею | **B. Line-art Explainer** | `/faceless-explainer` |
| Эмоциональный/интроспективный контент, отношения, психология | **C. Soft Emotional Overlay** | `/faceless-explainer` (мягкий вариант) |
| Показ UI-кита, дизайн-система, компоненты продукта | **D. Glass UI Kit** | `/product-launch-video` (как asset-источник, не как сцена целиком) |
| Корпоративный/светлый бренд, B2B, "процесс/стратегия" | **E. Light 3D Corporate** | `/product-launch-video` (light-mode ветка) |

Дефолт для mama_mozg — **не эти стили напрямую** (бренд использует coral/electric-blue
на белом со скетч-иконками, см. CLAUDE.md → "Мой бренд"). Стили A–E — внешние референсы
для клиентских/сторонних проектов либо как источник техник (glow, glass, line-art),
которые можно адаптировать под бренд-палитру.

## A. Neon Dashboard / SaaS UI

**Когда:** промо фич продукта, услуги в виде карточек, аналитика/метрики, соцсети-статистика, карта/трекинг.

**Фон:** чистый чёрный или тёмно-синий (#000000–#0a0a12).

**Цвет = категория**, не декор. Один доминирующий неоновый акцент на кадр:
- фиолетовый — услуги/креатив
- красный + золотой — гео/локация/маршруты
- синий — аналитика/данные
- зелёный — соцсети/успех/CTA

**Карточки:**
- радиус скругления ~24–32px
- полупрозрачная поверхность (glass) + тонкая светящаяся обводка
- лёгкий 3D-наклон/перспектива для ощущения стопки (не плоский список)
- внутри — вертикальный световой луч/прожектор позади текста, создаёт глубину

**Свет:** мягкие радиальные ореолы (halo), как будто подсветка снизу-по-центру
карточки или из-под pin-маркера на карте. Никогда — плоская заливка цветом.

**Типографика:** жирный чистый sans-serif (SF Pro/Inter-типа), белый заголовок,
приглушённо-серый second text. Крупные цифры-акценты (400%, 10/15) как фокальная точка.

**Иконки:** тонкая линия, белые, в скруглённом бордере-контейнере.

**Карта-вариант:** трассировка маршрутов светящимися пунктирными/сплошными линиями
между pin-точками, вертикальный луч от каждой метки, текстурный тёмный фон (aerial map).

**Формат:** портрет 9:16.

**Как делать в HyperFrames:**
- glow = `box-shadow: 0 0 60px 20px <accent>` + `filter: blur()` на псевдо-элементе позади карточки, не на самой карточке
- glass = `background: rgba(255,255,255,0.04)` + `backdrop-filter: blur(20px)` + `border: 1px solid rgba(255,255,255,0.08)`
- луч-подсветка = `radial-gradient(ellipse at 50% 100%, <accent> 0%, transparent 70%)` позади контента
- 3D-наклон карточек = `transform: perspective(800px) rotateX()` с небольшим углом, только `gsap.from()` на входе

## B. Line-art Explainer (объяснялки/мотивация)

**Когда:** мышление/бизнес-совет, самопомощь, "объясни идею одной метафорой" контент.
Это прямое попадание в `/faceless-explainer`.

**Фон:** чистый чёрный, без текстуры.

**Визуальный язык:** минимум цвета — линия рисуется как эскиз (белая/моно), не заливка.
Один сюжет = одна метафора на экран:
- пазл сходится руками = нетворкинг/отношения
- лестница + флаг = "думай о большем, начинай с малого"
- лук/мишень с разной точностью попадания = фокус/навык
- два line-графика друг под другом = сравнение "было vs стало"
- пунктирная линия между двумя точками + "?" у старта, подпись у финиша = путь к цели

**Акцент:** неон только точечно и по смыслу — мятный/зелёный (рост), золотой (цель),
красный/розовый (тревога/точность). Цвет = семантика, как и в стиле A.

**Текст:** крупная жирная подпись внизу кадра, часто как готовый вывод/тезис, не как
подпись к картинке ("Думая о большем, начинай с малого!"). На русском — это нормально
для этого языка, не транслитерировать в стиль A.

**Композиция:** много негативного пространства, диаграмма занимает 30–40% кадра,
центрирована, подпись — отдельным блоком снизу, не наложена на диаграмму.

**Формат:** портрет 9:16.

**Как делать в HyperFrames:**
- линии — SVG `stroke`, не PNG-иконки; анимировать через `stroke-dashoffset` (draw-on эффект)
- пунктирные коннекторы — `stroke-dasharray` + `gsap.from()` на `strokeDashoffset`
- графики — чистый SVG `path`, анимация через draw + точка/маркер на конце с `gsap.from(scale)`
- текст-вывод — появляется ПОСЛЕ того как диаграмма дорисовалась, не одновременно
- glow только на акцентный элемент (флаг, точка на графике, попадание в мишень), не на весь кадр

## C. Soft Emotional Overlay

**Когда:** интроспективный/психологический контент, отношения, "внутреннее состояние".
Более мягкая ветка `/faceless-explainer` — не energetic-growth, а contemplative.

**Фон:** чёрный, но с мягкими блёрными пересекающимися кругами вместо резкого neon glow.

**Свет:** белое мягкое свечение (не цветное), сфокусированное на центральном элементе
("You"). Второстепенные элементы — blur + низкий контраст, читаются как фон/шум мыслей.

**Типографика:** тонкий, не жирный шрифт — контраст с уверенным bold стиля A/B
намеренный, передаёт хрупкость/интроспекцию.

**Как делать в HyperFrames:**
- `filter: blur()` с разной интенсивностью по слоям (parallax глубины)
- центральный элемент — единственный в фокусе (`blur(0)`), это и есть композиционный якорь
- избегать резких neon-акцентов — единственный цвет допустим только как едва заметный tint

## D. Glass UI Kit (компонентная библиотека, не сцена)

**Когда:** не самостоятельная сцена, а источник форм для карточек/кнопок/полей внутри
сцен стиля A. Показывать UI-кит целиком имеет смысл только для продукта, который сам
и есть дизайн-система (например промо конструктора интерфейсов).

**Спецификация компонентов:**
- кнопки: капсульная форма (`border-radius: 999px`), градиент фиолетово-синий,
  внутреннее свечение по контуру
- поля ввода: скруглённый прямоугольник, тонкая glow-обводка при фокусе
- карточки: та же glass-формула, что в стиле A, но с чётким hard-edge содержимым внутри
  (не декоративным, а функциональным — аватар, текст, статус)
- toast/modal: те же ореолы, но компактнее, с иконкой-статусом

**Использование:** брать как reference для CSS-токенов (радиусы, тени, градиенты),
не копировать композицию кадра целиком.

## E. Light 3D Corporate

**Когда:** B2B/корпоративный тон, "процесс/стратегия/данные", светлый бренд.
Единственный светлый стиль в этой библиотеке — сознательно контрастирует с A–D.

**Фон:** светло-серый/белый градиент, без черноты вообще.

**Форма:** мягкий 3D-рендер (не плоская иконка) — например стопка карточек/папок
с лёгким пастельным градиентом (голубой), edge-highlight имитирует студийный свет,
не neon-glow.

**Типографика:** крупный, воздушный, много whitespace, текст — список ключевых слов
("Strategy / Content / Design / Data"), не полное предложение.

**Как делать в HyperFrames:**
- либо реальный 3D-рендер (Three.js/Spline-экспорт), либо CSS multi-layer с
  `box-shadow` слоями для имитации толщины стопки
- свет = мягкий верхний `linear-gradient` + edge highlight, не радиальный glow
- анимация — плавный `gsap.from()` со сдвигом/разворотом стопки, без резких появлений

## Сквозные принципы (все стили)

1. **Цвет = категория/смысл, не украшение.** Если в кадре несколько акцентных цветов —
   у каждого есть закреплённая роль (тип контента, статус, эмоция).
2. **Свет — источник, не заливка.** Glow всегда радиальный/направленный, эмулирует
   реальный источник (снизу карточки, из-под pin, за текстом), никогда не покрывает
   фон целиком плоским цветом.
3. **Одна идея на кадр.** Особенно жёстко в стиле B — диаграмма считывается за 1–2
   секунды, подпись подтверждает, а не объясняет заново.
4. **Негативное пространство — часть композиции**, не пустота, которую нужно заполнить.
5. **Текст появляется после визуала**, не одновременно — визуал создаёт вопрос,
   текст даёт ответ.
6. **Формат по умолчанию — 9:16.** Все референсы, кроме DOO (E), сняты под мобильный/Reels.
