# Application Tracker

## Что делает
Ведёт файл `tracker.csv` (создаётся при первом запуске рядом со скиллом или в
корне проекта — уточни у пользователя удобное место) со всеми действиями.

## Формат записи
| Дата | Вакансия | Компания | Локация | Ссылка | Рекрутер | Действие (отклик/коннект/сообщение/форма) | Статус (черновик/отправлено/ответ/отказ) | Заметка |

## Как работает

1. Перед тем как cover-letter-generator, application-form-filler или
   recruiter-outreach предложат новое действие — проверь tracker.csv: не
   откликались ли уже на эту вакансию / не писали ли уже этому рекрутеру.
   Если да — предупреди пользователя, не дублируй.
2. После каждого подтверждённого пользователем действия — добавь строку в
   tracker.csv со статусом "отправлено". Если по вакансии дополнительно была
   заполнена расширенная форма (application-form-filler) — отметь это в
   поле "Заметка", а не отдельной строкой в лимитах.
3. Перед началом каждой сессии outreach — посчитай, сколько действий каждого
   типа уже сделано сегодня, и сверь с `daily_action_limits` в
   `config/criteria.json`. Если лимит достигнут — сообщи об этом и не
   предлагай новых действий этого типа до следующего дня.
4. По запросу пользователя — покажи сводку: сколько откликов за неделю,
   сколько ответов, конверсия, разбивка по локации (Казахстан / Варшава).
