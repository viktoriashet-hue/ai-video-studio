# Resume Profile Match

## Что делает
Берёт список вакансий, прошедших фильтр job-search-filter, и оценивает
соответствие профилю из `linkedin-agent/config/profile.md`.

## Как работает

1. Прочитай `linkedin-agent/config/profile.md` — навыки, опыт, желаемые роли, регион,
   право на работу в ЕС.
2. Для каждой вакансии оцени:
   - Совпадение по роли/специализации (высокое / среднее / низкое).
   - Совпадение по ключевым навыкам из описания вакансии.
   - Совпадение по формату работы и региону (Алматы/остальной Казахстан/Варшава/remote).
   - Для Варшавы: если у вакансии стоит флаг "требуется EU work permit" — и
     в профиле не отмечено, что разрешение уже есть — понижай релевантность
     до "низкая" с пояснением "требуется разрешение на работу в ЕС,
     уточните в профиле", не отклоняй молча.
   - Если вакансия помечена RU-сигналом (русскоязычная команда/явно
     принимают СНГ) — это плюс к релевантности, но не заменяет совпадение по
     роли/навыкам.
3. Присвой каждой вакансии оценку релевантности (высокая/средняя/низкая) и
   короткое пояснение (1 строка), почему.
4. Сортируй в два уровня: сначала по тиру локации из `location_priority`
   (Алматы — tier 1 — всегда первым блоком), и только внутри тира — от
   самой релевантной к наименее. Не давай высокой релевантности вакансии из
   Варшавы обгонять по порядку среднюю/низкую вакансию из Алматы — тир
   важнее релевантности внутри него, потому что Алматы для пользователя
   приоритетный регион.
5. Вакансии с низкой релевантностью — не отклоняй молча, а покажи пользователю
   отдельным блоком с пометкой "сомнительно", пусть решает сам.
6. Не придумывай навыки или опыт, которых нет в `linkedin-agent/config/profile.md` — если
   информации не хватает для оценки (например, Experience ещё не заполнен),
   так и скажи прямо и предложи заполнить профиль подробнее.

## Результат
Итоговый список передавай в формате: Вакансия | Компания | Локация |
Релевантность | Почему | Ссылка — готовым для перехода к генерации откликов.
