# Recruiter Outreach

## Что делает
Готовит два коротких текста:
1. Connection request note (LinkedIn ограничивает длину — обычно до 300
   символов).
2. Follow-up сообщение после того, как рекрутер принял запрос.

## Как работает

1. Найди на странице вакансии рекрутера/HR, который её разместил (если указан).
2. Connection request note:
   - Очень коротко: кто ты, на какую вакансию откликаешься/интересуешься,
     почему пишешь именно ему.
   - Без воды, до 300 символов.
   - Язык — как в описании вакансии (русский, если вакансия в Казахстане или
     RU-сигнал; простой A2–B1 английский или польский по правилам из
     cover-letter-generator, если вакансия в Варшаве на английском/польском).
3. Follow-up сообщение (после принятия коннекта):
   - Напомни, по какой вакансии пишешь.
   - 1–2 предложения релевантного опыта.
   - Прямой вопрос/призыв к действию (например, "могу прислать резюме" /
     "можно уточнить детали вакансии?").
4. Покажи оба черновика пользователю на подтверждение. НЕ отправляй запрос на
   коннект и НЕ пиши сообщение сам.
5. Соблюдай дневные лимиты из `config/criteria.json` →
   `daily_action_limits.connection_requests` / `messages` — если лимит на
   сегодня уже достигнут (по данным application-tracker), предупреди
   пользователя и предложи отложить на завтра.
