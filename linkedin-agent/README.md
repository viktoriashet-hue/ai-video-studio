# LinkedIn Job Agent (Claude Code)

Агент помогает искать на LinkedIn вакансии, подходящие русскоязычному
специалисту в Казахстане и Варшаве, оценивать их релевантность профилю,
готовить сопроводительные письма, черновики ответов на доп. вопросы формы
заявки и сообщения рекрутерам, и вести учёт откликов — не откликаясь
повторно и не трогая уже устаревшие вакансии.

## Важно про безопасность аккаунта

LinkedIn User Agreement и Automated Activity policy прямо запрещают
автоматизированный сбор данных и автоматические действия (заявки, коннекты,
сообщения) без участия человека — подробности и ссылки в
`docs/tos-and-profile-notes.md`. LinkedIn детектирует такие паттерны жёстче,
чем большинство job-бордов, и банит аккаунты. Поэтому агент работает по
принципу **human-in-the-loop**:

- Claude в Chrome (browser use) читает страницы, ищет вакансии, заполняет
  черновики — сам не логинится и не скрейпит в фоне.
- Каждое действие, которое LinkedIn видит как "исходящее" (отклик,
  connect-запрос, сообщение, ответ в форме Easy Apply, подписка на
  рекрутера) — показывается пользователю на подтверждение перед отправкой.
  Финальный клик "Apply" / "Send" / "Connect" всегда делает пользователь.
- Между действиями — паузы, имитирующие обычный темп пользователя (не
  десятки действий подряд).
- Никаких headless-скриптов через LinkedIn API/scraping — работаем только
  через обычный залогиненный браузер пользователя.

Это тот же подход, что уже используется в проекте с hh.ru.

## Фокус поиска

- Регионы: **Казахстан** (Алматы, Астана, удалённо по КЗ) и **Варшава /
  Польша** (в т.ч. remote/hybrid).
- Аудитория вакансии: подходит русскоязычному кандидату — вакансия на
  русском, либо компания/команда русскоязычная, либо явно принимает СНГ-фон
  без требования продвинутого английского.
- Настраивается в `config/criteria.json` (профессии, ключевые слова, уровень
  английского, если он важен для фильтрации).

## Поток работы

1. **job-search-filter** — берёт список вакансий (по ссылке на поиск
   LinkedIn с фильтром по Казахстану/Варшаве или по вставленным пользователем
   карточкам), извлекает требования к языку/профессии и **дату публикации**,
   отфильтровывает по критериям из `config/criteria.json` и **отбрасывает
   устаревшие вакансии** (по умолчанию — старше 14 дней, настраивается через
   `posting_freshness.max_days_since_posted`).
2. **resume-profile-match** — сверяет отфильтрованные вакансии с
   профилем/резюме пользователя, ранжирует по релевантности (включая
   формат работы и совместимость по локации/визе), отсеивает явно не
   подходящие.
3. **cover-letter-generator** — для каждой подходящей вакансии готовит
   короткое сопроводительное письмо/отклик под конкретную вакансию, на
   русском или простом английском/польском в зависимости от рынка.
4. **application-form-filler** — если у вакансии есть Easy Apply / доп.
   вопросы формы (телефон, опыт в годах, ожидания по зарплате, разрешение на
   работу, релокация и т.п.) — готовит черновик ответов из
   `config/profile.md`, явно помечает вопросы, на которые не может ответить
   уверенно (виза, зарплата, доступность) — их решает сам пользователь.
5. **recruiter-outreach** — готовит текст connection request и follow-up
   сообщения рекрутеру, который ведёт вакансию.
6. **application-tracker** — ведёт список: вакансия, компания, локация,
   рекрутер, статус (черновик / отправлено / ответ получен / отказ), дата,
   чтобы не дублировать отклики и не превышать дневные лимиты.

Пользователь на каждом шаге 3–5 видит черновик и жмёт "отправить"/"apply" сам
— либо через Claude в Chrome одним подтверждающим действием.

## Настройка

1. Заполните `config/profile.md` — специализация, опыт, навыки, реальный
   уровень английского, целевые роли, регион, ожидания по зарплате. Часть
   полей уже предзаполнена по публичным данным профиля (см.
   `docs/tos-and-profile-notes.md`) — Experience/Skills LinkedIn прячет без
   логина, их нужно вставить руками (текстом резюме или экспортом с
   LinkedIn: "Ресурсы" → "Сохранить в PDF" на своей странице).
2. Отредактируйте `config/criteria.json` под свои критерии: профессии,
   ключевые слова-исключения, свежесть вакансий, дневные лимиты действий.
3. Начинайте сессию с job-search-filter, указав ссылку на поиск LinkedIn Jobs
   с фильтром по Казахстану или Варшаве (или вставив карточки вакансий
   вручную), и двигайтесь по пунктам потока работы выше.
