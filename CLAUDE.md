# AI Video Studio

Ты мой AI-редактор видео. Этот воркспейс собирает полный пайплайн:
сырое видео → монтаж → удаление паразитов → моушн-графика → финальный MP4.

---

## Стек

**video-use** (browser-use/video-use) — монтаж talking-head, удаление слов-паразитов, субтитры, базовый колоргрейд.
**faster-whisper** — транскрипция через faster-whisper (модель medium, язык ru), работает локально в контейнере, без внешних API.
**HyperFrames** (heygen-com/hyperframes) — HTML-нативная моушн-графика: интро, оверлеи, анимированные тексты, промо-вставки.
**Remotion** — запасной движок для анимации, если задача требует React-компонентов.
**FFmpeg** — обязателен для всего. Всегда на $PATH.

## Пайплайн по умолчанию

### Шаг 1. Монтаж (video-use)
Когда я даю тебе сырой файл:

1. Прочитай SKILL.md из `~/.claude/skills/video-use/`
2. Прочитай `helpers/` — там все скрипты
3. Инвентаризируй исходники, предложи стратегию монтажа
4. Жди моего подтверждения
5. Режь по речевым границам, убирай паузы >0.3с
6. Вырезай слова-паразиты: "эм", "ну", "вот", "да", "короче", ложные старты
7. Аудио-фейды 30мс на каждом стыке — обязательно
8. Самооценка на каждом стыке через `timeline_view` перед показом мне
9. Все выходные файлы — в `<папка_с_видео>/edit/`

### Шаг 2. Субтитры
- 2-слова, UPPERCASE по умолчанию
- Или под мой стиль: спрошу отдельно

### Шаг 3. Моушн-графика (HyperFrames)
После монтажа, когда я прошу добавить анимацию:

1. Запусти `/hyperframes` skill для роутинга задачи
2. Для интро/промо: используй `/product-launch-video` или `/faceless-explainer`
   - Моушен-вставки внутрь говорящей головы (лицо ↔ графика на одном голосе) → клипы здесь, сборка `/aroll-motion-splice` (Шаг 4), звук `/sound-design` (Шаг 5)
   - Безлицевой рилс-инструкция «по шагам» (кинетическая типографика, графит/крем/синий, ступенчатые шторки, CTA КАНАЛ) → `/kinetic-steps` — у него свой стиль, MOTION_PHILOSOPHY ниже к нему не применяется
3. Стиль по умолчанию (MOTION_PHILOSOPHY):
   - Чёрный фон, негативное пространство как дизайн
   - Свет как бренд, не цвет — хромированные градиенты, мягкие ореолы
   - Камера никогда не стоит: даже на "статичных" кадрах что-то двигается
   - Средняя длина сцены: ~1.5 сек, одна идея на кадр
   - Переходы: push slide 60%, zoom through (opener), blur crossfade (outro)
4. Блоки из реестра: `npx hyperframes add <block>` для скорости, ручная сборка — для ключевых сцен
5. Анимации — через GSAP, только `gsap.from()` на входе, transitions на выходе
6. Рендер: `npx hyperframes render --quality draft` для итераций, без `--quality` для финала

### Шаг 4. Сборка: лицо + моушен на одном звуке → `/aroll-motion-splice`
Когда в говорящую голову вставляем моушен-графику (стиль «как у Молянова»):
1. Голос спикера — мастер-дорожка, идёт без единого разрыва. Моушен-клипы рендерятся **без звука** и только перекрывают картинку.
2. Раскадровка таблицей (время · слова · ЛИЦО/МОУШЕН · что на экране · переход) → Вике одним сообщением.
3. Каждый моушен-блок = HyperFrames-композиция ровно по длине отрезка речи + `<clip>.events.json` (появления, печать, счётчики — для звука).
4. `python3 .claude/skills/aroll-motion-splice/scripts/splice.py edit/splice.plan.json --draft` → стыки по словам, переходы, punch-in на возврате к лицу, сквозные субтитры последним слоем.
5. Норма: моушен 55–70% хронометража, лицо — хук, эмоции, мнение, CTA; новый элемент моушена на каждое ключевое слово.

Старый вариант (video-use explainer: каждый блок = `{video: job_id, audio: job_id}`) — только если звук блоков действительно разный.

### Шаг 5. Звук → `/sound-design`
После склейки (или после любого моушен-рилса):
1. `python3 .claude/skills/sound-design/scripts/auto_cues.py edit/spliced.seams.json -o edit/cues.json --bgm motion_only` — whoosh на стыках, pop/typing/tick на событиях моушена, riser перед первым моушеном.
2. `python3 .claude/skills/sound-design/scripts/sfx_mix.py edit/cues.json -o edit/final.mp4` — эффекты шире голоса, подложка с дакингом, −14 LUFS линейно (динамика голоса не трогается).
3. Проверка: ebur128 (≈ −14 LUFS, пик ≤ −1 dBFS) + спектрограмма side-канала — вжухи ровно на стыках.
4. Свои звуки Вики — в `.claude/skills/sound-design/assets/sfx-user/` (перекрывают встроенные по имени).

## Правила

- Никогда не трогай таймлайн без моего подтверждения стратегии
- Транскрипция через faster-whisper (модель medium, язык ru), работает локально в контейнере, без внешних API
- После свежего клона video-use — примени `patches/video-use/apply.sh` (см. `patches/video-use/README.md`), иначе транскрипция откатится на ElevenLabs Scribe из апстрима
- Все выходные файлы — в `edit/`, репо всегда чистый
- После монтажа — лентируй через `npx hyperframes lint`, исправь все ошибки до показа
- Звук голоса никогда не режется вместе с картинкой при вставке моушена; звук моушен-клипов не используется — все эффекты только в одном финальном миксе (`/sound-design`)
- Перед показом склейки — контакт-лист кадров на каждом стыке (нет пустых/чёрных кадров) и проверка, что аудио склейки побитово равно A-roll
